# 定时任务 Cron

内置 Cron 表达式调度器。

## 配置

创建 `config/cron.php`：

```php
return [
    'tasks' => [
        '清理日志' => [
            'cron' => '0 0 * * *',
            'task' => [App\job\CleanLog::class, 'handle'],
        ],
        '备份数据' => [
            'cron' => '0 3 * * *',
            'task' => 'App\command\Backup@execute',
        ],
    ],
];
```

## 运行

由系统 crontab 每分钟调用一次：

```bash
* * * * * php lee cron:run
```

调度器自动判断并执行到期任务。

## Cron 表达式

```
* * * * *
│ │ │ │ │
│ │ │ │ └── 星期几 (0-7, 0 和 7 都是周日)
│ │ │ └──── 月份 (1-12)
│ │ └────── 日期 (1-31)
│ └──────── 小时 (0-23)
└────────── 分钟 (0-59)
```

常用示例：
- `* * * * *` — 每分钟
- `0 * * * *` — 每小时
- `0 0 * * *` — 每天零点
- `0 9 * * 1` — 每周一 9 点
- `*/5 * * * *` — 每 5 分钟
